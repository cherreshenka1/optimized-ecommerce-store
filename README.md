# Optimized E-Commerce Store

Портфолио-проект интернет-магазина с акцентом на интерактивный UI,
lazy loading изображений, калькулятор доставки, корзину и имитацию аналитики.

## Что есть

- Каталог товаров с фильтрами по категории
- Карточки товаров со слайдером изображений
- Корзина и расчёт стоимости
- Калькулятор доставки
- Имитация Яндекс.Метрики и Google Analytics
- Отображение LCP / CLS / FCP в футере
- Lazy loading изображений
- CSS-анимации

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

## Деплой

```bash
npm run deploy
```
