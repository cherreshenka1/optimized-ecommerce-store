# optimized-ecommerce-store

Самостоятельный интерактивный проект: вещи для дома.

[Открыть сайт](https://cherreshenka1.github.io/optimized-ecommerce-store/) · [Кейс](https://cherreshenka1.github.io/portfolio/projects/optimized-ecommerce-store/) · [Промпт и критерии доработки](https://github.com/cherreshenka1/portfolio/blob/main/prompts/optimized-ecommerce-store.md)

## Сценарий

Сравнить товары, собрать корзину, выбрать доставку и сохранить учебный заказ.

Категории помогают выбрать товар. Корзина учитывает количество, город и способ доставки; пустой заказ стоит ноль. Учебный заказ сохраняется локально.

## Границы

Магазин-концепция. Оплата и реальная доставка не подключены.

## Проверить вручную

1. Выбрать категорию.
2. Добавить товар.
3. Настроить доставку.
4. Сохранить демо-заказ.

Проверены основной сценарий и адаптивная вёрстка при ширине 390 и 1280 px. Это проверка прототипа, а не сертификация готовности к промышленной эксплуатации.

## Визуальная доработка

Оболочка обновлена 02.10.2026: спокойная палитра, компактные рабочие панели и предметные материалы. Источники открытых данных: `public/data/open-data.json`; происхождение фотографий: `public/data/photo-sources.json`. Фотографии сохранены локально.

## Разработка

React 18, Vite 5. Node.js 20+.

```sh
npm ci
npm run dev
npm run build
```

`npm run deploy` собирает приложение и публикует `dist` в ветку `gh-pages` текущего репозитория.
